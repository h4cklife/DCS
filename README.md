# DCS modules

Modules and tools for [DCS World](https://www.digitalcombatsimulator.com/), developed by
[h4cklife](https://github.com/h4cklife).

Each module lives in its own folder with its own documentation, tests and releases.

## [ATCAI](ATCAI/) — an air traffic controller you can talk to

[![ATCAI build](https://img.shields.io/github/actions/workflow/status/h4cklife/DCS/atcai.yml?branch=main&label=build&logo=github)](https://github.com/h4cklife/DCS/actions/workflows/atcai.yml)
[![Latest release](https://img.shields.io/github/v/release/h4cklife/DCS?filter=atcai-v*&label=release)](https://github.com/h4cklife/DCS/releases)
[![Licence](https://img.shields.io/github/license/h4cklife/DCS)](LICENSE)

Ask for startup, taxi, takeoff, a circuit join or landing clearance by voice, and hear
ATC answer — using the real wind, the real altimeter setting, and the runway that suits
the weather. Works in every mission, with nothing to set up per mission.

- **[Getting started](ATCAI/GETTING-STARTED.md)** — for players. Download, install, fly.
- **[Developer README](ATCAI/README.md)** — how it works, how to build and test it.

Single-player only.
